## What is a customer journey map template, and what's in ours?

**A customer journey map template is a reusable grid that a team fills with user research to show how one persona moves through one scenario, stage by stage.**

Nielsen Norman Group (NN/g) describes a journey map as [a picture of the process a person goes through to accomplish a goal](https://www.nngroup.com/articles/journey-mapping-101/). The template is that picture before anyone draws on it: journey stages across the top, lanes down the side. Ours has 6 header fields, 5 editable stage columns and a lane count of 8. Its file formats are PDF, SVG, PNG and CSV, and the Feeling lane uses an emotion scale from -2 to +2.

### What is customer journey mapping?

**Customer journey mapping is the process of researching and drawing the stages one type of customer goes through, with their actions, thoughts and emotions and the opportunities those reveal.**

A journey map template is only the grid; the research fills it. A customer journey mapping template is the same grid under another name, so download whichever format your team edits fastest.

## How does a customer journey map differ from other UX maps?

**A customer journey map follows one persona across a whole relationship with a company; a user journey map follows the same person through one product task, both from user research.**

A user journey map uses the same grid, scoped to one product task instead of the whole customer relationship. Product teams often call the product-scoped version a UX journey map, and the same file works as a user journey map template: rename the stages to the steps of one task.

NN/g's [UX mapping cheat sheet](https://www.nngroup.com/articles/ux-mapping-cheat-sheet/) separates the other maps by point of view, scope and time order. The table compares six maps on those points and the question each answers.

| Map | Point of view | Scope | In time order? | Question it answers |
|---|---|---|---|---|
| Customer journey map | One user type | Whole relationship with a company, across channels | Yes | Where does the experience break or delight? |
| User journey map (UX journey map) | One user type | One task in one product | Yes | What happens, and how does it feel, during this task? |

A service blueprint adds the frontstage and backstage actions of staff plus their support processes, so draw one after a journey map shows where the problem sits. An empathy map skips time order, and an experience map covers people in general, before any product exists.

### What is a user journey?

**A user journey is the sequence of steps a person takes in a product to reach one goal, such as booking a first appointment.**

A map of that journey adds what they think and feel at each step, plus what happens outside the product, like a call to support. Write the goal in the header's scenario field first.

### How does a user journey map differ from a user flow?

**A user flow is a screen-by-screen diagram of the paths any user can take, while a user journey map shows one research-based persona's experience, with emotions and off-screen steps.**

Teams settle the user journey map vs user flow question by order of work: map the journey first to find which moment to fix, then draw a user flow for that moment's screens.

## Which stages and lanes belong in a journey map template?

**A journey map template should hold the 5–7 journey stages your user research finds and 8 lanes, so each column shows where one persona actually struggles.**

We set the stage count at 5–7 per map, because fewer hides the hard moments and more turns the grid into a user flow. Keep the map scope to one user type and one scenario, as NN/g advises one point of view per map. Our research program sets the persona count at 2–4, each built from user interviews rather than invented in a workshop like a marketing buyer persona.

### What are the 7 steps of the customer journey?

**No single standard defines a 7-step customer journey; one common 7-stage set is awareness, consideration, decision, purchase, onboarding, retention and advocacy.**

That set suits a lifecycle customer journey map for a whole brand. For product work, stages named from interviews beat it: "Consideration" tells a designer nothing about which screen to change, while "Set shift rules" does.

### Current-state, future-state and day-in-the-life maps

**A current-state map shows today's journey, a future-state map shows the journey you plan to build, and a day-in-the-life map covers one person's whole working day.**

The download is a current-state map by default; a future-state map reuses the grid after research, and a day-in-the-life map suits shift work, where your product is one tool among many.

### What each lane needs

A customer journey map template only saves time if every cell can point to a source:

- **Persona and scenario header:** the research base line (methods, sessions, dates) lets readers judge the map first.
- **Journey stages:** named after what participants did, in their order.
- **Touchpoints:** every screen, email, call and person, since problems often sit between channels.
- **Emotion curve:** its lowest point is the moment of truth, where the user decides to stay or leave; high points are moments of delight.
- **Evidence lane:** source and evidence level for every cell, so guesses stay visible.
- **Opportunities and owners:** one internal owner and one metric each, or nobody acts on them.

The Thinking lane holds thoughts and mindsets as verbatim quotes, never a team summary. Rename the stage columns from your own notes before you write a single cell.

## Where does evidence for each journey map lane come from?

**Each journey map lane needs its own kind of user research: interviews fill Thinking, contextual inquiry fills Doing and Touchpoints, and analytics and support tickets count pain points.**

NN/g's Kate Kaplan calls journey mapping [a qualitative-research process](https://www.nngroup.com/articles/customer-journey-mapping/) and notes that quantitative data alone cannot build the story. Numbers back up a map; they never write it.

Our research program plans an interview count of 10–15 one-hour user interviews per user group. Contextual inquiry means watching people do real work where they do it and asking about it as they go; we set the observation count at 4–6 users, on site, for example at a clinic front desk. The evidence lane gives every cell an evidence level from a four-letter key:

- **H, heard:** said in interviews, with a count such as "9 of 12".
- **O, observed:** seen during site visits or session recordings.
- **M, measured:** counted in analytics or support tickets.
- **A, assumed:** team knowledge nobody has checked yet.

The intro's workshop cell is an A; its research cell is an H and an O. NN/g calls a map built from what a team already knows a hypothesis map, and the hypothesis map vs research map distinction matters: the first plans a study, the second is the deliverable. Observed cells cannot be filled from a desk; our researchers run those 4–6 sessions in our program's generative fieldwork step (7–15 days). Mark every cell on your map before you book interviews.

## How do you fill a customer journey map template in 7 steps?

**Fill a customer journey map template in 7 steps, from fixing one persona and scenario through interviews, contextual inquiry and synthesis to a validated map with owners.**

These steps answer how to create a customer journey map and how to create a user journey map alike; only the scope in step 1 changes.

1. **Frame the scope.** One user type, one scenario, 3–5 research questions. Output: a scope sheet.
2. **Gather what you have.** Pull analytics, support tickets and past studies, then draft a hypothesis map. Output: mostly A cells.
3. **Run user interviews.** 10–15 one-hour sessions per user group about the last time they did the task. Output: verbatim quotes.
4. **Observe with contextual inquiry.** Watch 4–6 users do the task where they work. Output: observation notes and workarounds.
5. **Tag and cluster.** Tag notes in Dovetail, then use affinity mapping, which groups related findings into clusters, to sort them by stage. Output: clusters per stage.
6. **Write each lane.** Name stages from the clusters, quote verbatims, plot the emotion curve and mark evidence levels. Output: a sourced map.
7. **Validate and assign.** Walk 2–3 participants or frontline staff through it, validate and refine, then give each opportunity an owner and a metric. Output: a validated map.

In our program these steps sit inside a research timeline of 4–8 weeks, run as [our 5-step UX research process](/services/ux-research-services/#how-does-the-ux-research-process-work); the map comes out of its synthesis and readout step (4–7 days). Start with step 2 this week, because a hypothesis map shows which interviews to book.

## How do you turn a journey map into decisions, not wall art?

**A journey map drives decisions when every opportunity has one owner, one metric and a date, and the team ranks them by the lowest emotion points and the user research behind each.**

Our ranking rule weighs how far the emotion curve drops against the evidence level: observed and measured outrank heard, and heard outranks assumed. The table ranks the worked example's top three opportunities with their internal ownership and metric.

| Rank | Opportunity (stage, feeling, evidence) | Owner | Metric |
|---|---|---|---|
| 1 | Swap requests inside the app (4, -2, H and M) | Mobile lead | Share of swaps handled in the app |
| 2 | One screen for all shift rules (2, -1, H and O) | Design lead | Time to set shift rules |
| 3 | Side-by-side check view (3, 0, H and O) | Design lead | Rotas published without the spreadsheet |

Pick each metric from the key performance indicators (KPIs) the owner already reports, so the map's metrics and KPIs need no new dashboard. A journey map is a living document; the FAQ on updates gives our review cadence. In [how we mapped the Vocable creator journey](/case-studies/vocable/), stakeholder interviews split the creator's work into four phases, planning, drafting, optimizing and publishing, and each screen answered a problem heard in those interviews.

A map of mostly A cells cannot settle a priority argument, and teams that disagree about priorities with no shared personas or journey maps match a situation our UX research page lists for investing in research. Put an owner's name in every Opportunities cell before the meeting ends.

## Which customer journey map mistakes waste the template?

**Six customer journey map mistakes waste the template, and the worst is presenting an assumption-only map as user research, because nobody can then tell guesses from findings.**

- **Assumed cells sold as research**, because the map hides its guesses; the evidence lane shows every A.
- **Several personas on one grid**, because their emotion curves cancel out; draw one map each.
- **Funnel stages on a product task**, because "Consideration" names no screen; name stages from clusters.
- **An emotion curve with no quotes**, because a -2 nobody said is a guess; quote every point.
- **Too many lanes**, because nobody reads a 14-lane map; keep 8.
- **A map never updated**, because cells go stale after releases; date the evidence lane.

Before you share a map, check that every quote carries a participant ID, every cell an evidence level and the header a review date; send any map that fails back to the step that owns it.

## FAQs

### How do you make a customer journey map in PowerPoint?

Insert our SVG file with Insert > Pictures, then select it and use the Convert to Shape option to edit each box and label. Microsoft's guide to [editing SVG images in Microsoft 365](https://support.microsoft.com/en-us/office/edit-svg-images-in-microsoft-office-365-69f29d39-194a-4072-8c35-dbe5e7ea528c) describes that option; for a table instead, paste the CSV grid into a PowerPoint table.

### How do I create a user journey map?

Pick one user type and one product task, then fill the template from 10–15 user interviews per user group and on-site observation of 4–6 users. Name the stages after the task's steps and validate with participants, following the [7 steps above](#how-do-you-fill-a-customer-journey-map-template-in-7-steps).

### Can you build a customer journey map template in Excel or Google Sheets?

Yes. Open our CSV file in Excel, Google Sheets or Numbers: the header fields sit on top, column A lists the 8 lanes and columns B to F hold the five stages. A spreadsheet suits evidence notes and links to recordings, while a Miro or FigJam board suits a workshop.

### How many personas should one journey map cover?

One per map, following one scenario, so the emotion curve and quotes share one point of view. Our research program builds 2–4 personas with 1 journey map each; when two of them share a journey, map both and compare the curves.

### Can AI create a customer journey map?

Yes, but only as a first draft. An artificial intelligence (AI) tool such as ChatGPT can propose stages and fill a hypothesis map, yet every cell it writes stays an A until interviews or observation back it.

### How often should you update a customer journey map?

Update it after each new study or major release that touches the journey; that review cadence is our practice, not a published standard. Date every evidence entry, so stale cells show and the next study can target them.
