## Lessons sent

- **semantic-content-writer**: an escalated rule at the top, because this is a repeat (10-07 blog, 10-09 location): never stack a keyword in front of another noun, tested with the "this agency" swap. The description rule now has a fallback for when the full offer clause does not fit: end with the post's own CTA verb in 3–4 words and shorten the list items, never drop them. New lesson: when a list shares one verb, test each item with that verb.
- **content-qa**: an escalated FAIL for stacked keywords, with a grep. New lesson: quote every subject–verb pair in a list of 3 or more items in bold answers and descriptions.
- **seo-keyword-researcher**: reversed-order keywords (city or qualifier last) also need a `keywordCarrier`, with a compound pattern.
