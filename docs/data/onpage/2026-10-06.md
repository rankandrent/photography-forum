## Proposals for the owner

- **Case-study stubs** (fortna, apex-hcm, toolsgroup): all three still carry `TODO: replace with the full case study`. Each needs challenge, research, design decisions and outcome sections (≥ 600 words, ≥ 3 H2s), written from real project material only. Fortna also needs a client-and-topic metaTitle, e.g. "Fortna Case Study: Warehouse Error Resolution UX".
- **About page**: no page links to /about/ from its content (footer only). Add 2–3 contextual links, e.g. from the home team section, /contact/, and author pages ("our design team"). The page also needs more first-hand depth (team, process, proof), currently 384 words.
- **/industries/startups/ vs /services/ui-ux-design-services-for-startups/**: these two pages compete for very close queries. Decide which one owns "startup UI UX design agency", and make the other link to it.
- **/industries/ecommerce/**: the slug check fails because the anchor is "e-commerce" and the slug is "ecommerce". This is a script tokenisation issue, not a page problem. Do not change the URL; teach the script to treat "e-commerce" as "ecommerce".

## Lessons sent

- **semantic-content-writer**: the meta description must open with the exact keyword phrase, question words included (choose-ux-research-agency dropped "how").
- **content-qa**: run `npm run onpage -- /blog/<slug>/` and FAIL below 95. Check the description for the keyword, not only for length.
- **seo-keyword-researcher**: the brief must carry the exact phrase for title and description. Where an industry page's `anchor` and its meta wording disagree (Finance vs "Fintech"), record which one the page owns.
